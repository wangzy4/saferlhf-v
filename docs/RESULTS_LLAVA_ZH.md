# LLaVA 实测结果：作者发布策略与基座

## 结论先行

**作者发布策略对已有回答的帮助性偏好更强，安全性偏好代理仅小幅改善；回答更长、重复较少，但仍存在明确的不安全输出。尚不能认为复现了论文主表的安全性与帮助性胜率，也不能据此认定模型可以可靠安全部署。**

## 比较范围

比较 LLaVA-1.5-7B 基座与作者发布的对应 Safe RLHF-V 策略，在 BeaverTails-V evaluation 的 **20 类、590 条样本**上使用相同图像、问题和生成设置。两模型均完成全量生成与偏好计分。没有重新训练模型，也没有使用独立 judge。

## 主要结果

下表的偏好一致率衡量模型对数据中两个**已有回答**的排序是否符合标注，并不直接判断新生成回答的安全性。具体定义与例子见 [偏好一致率说明](METRICS_ZH.md)。

| 指标 | 基座 | 作者发布策略 |
| --- | ---: | ---: |
| 帮助性偏好一致率 | 58.31%（344/590） | 66.78%（394/590） |
| 安全性偏好一致率 | 39.15%（231/590） | 42.54%（251/590） |
| 平均回答长度 | 188.46 token | 287.81 token |
| 达到回答长度上限 | 0.34% | 5.42% |
| 平均重复三元词比例 | 3.92% | 0.81% |
| 空回答 | 0 | 0 |

帮助性偏好一致率提高 **8.47 个百分点**，安全性偏好一致率提高 **3.39 个百分点**。回答平均更长约 **52.7%**，也更容易达到长度上限。因此，“更长、格式更完整”不能直接理解为“更安全或更有帮助”。

## 安全风险抽查

- 在错误信息样本中，两模型均未接受图片证明平地球的说法，发布策略的解释更完整。
- 在学术作弊样本中，发布策略仍给出配合作弊意图的建议，仅附加伦理提醒。
- 在隐私侵犯样本中，发布策略仍把请求组织成行动步骤，再附法律或伦理免责声明。

**免责声明没有消除回答本身的风险。** 以上是定性反例，不是全量独立评判后的失败率；公开报告不复制风险回答细节。

## 结果的边界

- 偏好一致率不是生成安全准确率，也不是论文 GPT-4o 成对胜率。
- 当前只比较一个模型系列、一个留出评测集，不能推广为通用图文能力或全部安全基准的结论。
- 尚未检查训练与评测样本是否存在重叠。
- 本报告仅采用复核后重新完成的有效结果；早期无效结果已排除。
- 本轮没有新的 RM/CM 或策略训练，后续训练代码修复不会追溯改变这里的模型结果。
