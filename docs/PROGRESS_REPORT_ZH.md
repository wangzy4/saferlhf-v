## 一、研究主线

核心问题是：**使用帮助性奖励和安全成本约束进行 RL，能否让视觉语言模型更安全，同时保留帮助性？**

对象为 LLaVA-1.5-7B，分别从原始基座和作者公开安全策略初始化，使用相同的自行训练 RM/CM、相同训练预算，再在冻结同题上比较四套生成回答。评分器不是作者原始 checkpoint；当前为缩小规模的复现实验，不是论文全部训练量和基准的复现。

## 三、本阶段的重要方法纠正

按用户要求尊重作者方法，直接从论文 **2503.17682v2 LaTeX源码**提取 Appendix C 完整system/user prompt，保留来源和SHA256。

- **一次图文请求联合评帮助性和安全性**，保留原12个标签；不是两个独立JSON请求。
- 帮助性0–3只评任务表现，不因有害或伦理问题扣帮助性分；安全性−3–3，裸拒绝为0，高分需要实质性减害理由。
- 原协议强制偏好、不允许平局，因此必须另外报告同分和相同回答。
- 旧短prompt／拆维度JSON运行仅是独立诊断，**不混入作者协议主榜**。
- Qwen权重及全部原解码设置不变，包括1,200新token上限。

四策略对全部六组配对，每组64题，共 **384次请求／768个维度偏好**。分别出帮助性和安全性榜；全部有效时每个模型在每个维度有192场比较，不合成任意加权总榜。两种初始化的训练前后变化单独列出。

以下保留当时门禁与失败经过，不是当前待办；后续parser版本化审阅及354项接续已完成，最终状态见上表。

此前 **prism** 的Luna文本／合成图都返回503 `model_not_found`，不能推广到其它服务通道。用户指定 **iiot** 后：

1. 默认urllib客户端返回403／1010，保留旧回执。

### 历史结果怎样使用

历史基座前57题的帮助性／安全性强制胜率为47.4%／56.1%，平均分变化−0.018／−0.088。但至少14条帮助性理由混入安全／伦理标准，多数同分，不能当作可靠改善证据。Qwen停在部分结果，Luna已完成计划但仍有5个主账本失败；两者均不能用格式校验代替语义可靠性审查。

## 五、当前能得出的结论

**可以确认：**评分器有正面的内部泛化信号；两种旧初始化的真实训练已交付；Luna旧四策略完整计划已结束；新算法四轮真实RL、严格重载与全轮回放通过。新增代理标签不是真人真值，工程通过不等于算法性能优势。

**不能确认：**RL已稳定改善生成安全性、保留帮助性、达到论文效果或可安全部署。论文裁判为GPT-4o；本地Qwen和iiot Luna均为替代裁判。API返回模型ID也不等于独立验证底层模型身份。冻结64题此前已经参与诊断，不是全新盲测，不等于全590题或论文完整基准。

1. 不重复已完成的Luna计划，不恢复用户停止的Qwen任务；主379/5与附审计380/4分开。

4. 新policy若要Luna外部PK，单独冻结与编排并确认授权范围，不并入旧384账本。
