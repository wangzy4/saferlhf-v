# 当前进展：原生 Qwen 评分器 → 四卡 Joint-PPO 5K

> **2026-10-20 阶段快照。** 本页聚焦研究主线、计划规模、已完成任务与下一步，不展开服务器、实现排错或私有运行材料。长期目标和完整任务关系见[项目主线总览](PROJECT_SUMMARY_ZH.md)。
>
> **当前结论：Qwen 原生 RM／CM 的5K输入准备和CPU审计已完成；正式评分器训练、正式策略5K均为0次更新。已按“仅CPU收尾后停止”结束本轮，不在后台等待或自动启动GPU训练。**

## 1. 主线目标与计划

最终目标仍是验证：**有限外部反馈下，Joint-Gradient 能否比均匀查询／控制变量和 Marginal-Gradient 更有效地改善安全性—帮助性表现。** 外部标签为 AI 评判反馈，不是人类风险认证。

当前优先推进下面这条路线，而不是直接继续旧7B长跑：

1. **用作者公开偏好数据训练原生 Qwen3.5-4B RM／CM。** 复用作者标量评分头和训练目标思想，保留 Qwen 原生骨干和图文模板。
2. **先验证评分信号适合 Qwen 的回答。** 偏好排序、绝对帮助性／危险成本和策略收益分开检查。
3. **接回四卡 Qwen LoRA Joint-PPO＋PTX／双 critic。** 用5,000个唯一 prompt 开展计划训练，少量真实揭示的反馈用于校正代理信号。
4. **在预算匹配条件下验证方法收益。** 5K训练成功本身不等于 Joint 优于对照；后续对照与独立终点评测需另行冻结方案和预算。

两个训练阶段采用不同参数方案：**RM／CM 是语言＋视觉 merger／投影＋无 bias 标量头全参训练、冻结视觉 tower；actor 仍为 LoRA**。没有把 LLaVA 模型套到 Qwen，也没有把严格联合梯度计算改成 sketch／参数抽样。

## 3. 为什么现在先重训评分器？

旧评分器的偏好学习结果并未被推翻。此前作者规模 LLaVA RM／CM 复现已完成，公开偏好评估排序约为 **81.86%／79.49%**，见[原结果](AUTHOR_SCALE_RM_CM_ZH.md)。

问题是：**旧模型上的成对排序结果，不能自动转化成对 Qwen 新回答的可靠代理奖励／成本。** 本次 Qwen 校准实际使用旧小规模 LLaVA 代理，不是作者原始权重，也不是约30K那组评分器。

在128条验证回答上，旧代理经映射后：

| 检查 | 结果 | 结论 |
| --- | --- | --- |
| RM 与外部帮助性反馈的相关性 | Spearman约 **−0.070**；MSE未胜常数基线 | 不足以作为当前策略的帮助性信号 |
| CM 对 unsafe 的区分 | AUC约 **0.624**；unsafe仅5条 | 未通过筛查，正例少也使估计不稳定 |

结束位置反事实可改善部分 CM 排序，但没有修复 RM，也不足以直接放行。因此选择**换成原生 Qwen 评分器，再决定是否恢复策略训练**，而不是用更多策略反馈掩盖这个问题。

## 4. 计划规模与预算保持什么不变？

### 评分器：已有公开标签，不占策略纠正额度

- RM、CM 各使用**同一批5,000对**公开偏好样本，另有512对内部验证。
- 各固定 **3 epochs／939次更新**，每 epoch 313次；完整保留尾8对，不丢成4,992对。
- 原始帮助性、安全偏好和 harmless rating 保持不变，不另买5K标签，不按验证结果挑最佳 epoch。

### 策略：四卡、5K唯一 prompt、625条训练纠正反馈

- 计划 **5,000个唯一 prompt／160次策略更新**，PPO＋PTX／双 critic。
- 每1,000题为31个满32题池＋1个8题池；对应每满池4条查询、尾池1条查询，五段共 **625条训练反馈**。
- 每1,000题保存完整可变状态；只有新版本验证并原子提交后才清旧，正常仅保留最新完整 checkpoint。
- 已发生的 **192条校准反馈保留记账**；625条训练纠正额度尚未使用。当前Qwen上限合计817，额外终点评分预算0，不默认扩额。
- 原7B方案与预算单独保留、当前延后；不算成Qwen进度，也不自动启动。
