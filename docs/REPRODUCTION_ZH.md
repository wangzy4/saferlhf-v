# Safe RLHF-V 复现进展

## 当前结论

**已完成作者发布的 LLaVA-1.5-7B 策略与基座的全量推理比较，尚未完成 RM/CM 训练和完整 Safe RLHF-V 训练复现。论文主表中的安全性、帮助性胜率还没有得到独立验证。**

作者发布策略的帮助性偏好代理高于基座，安全性偏好代理仅小幅提高；输出抽查仍有明确风险，不能据此认为模型已经达到可靠安全部署要求。

## 当前实验能说明什么

在同一批 590 条 evaluation 上：

| 已有回答的偏好排序一致率 | 基座 | 作者发布策略 | 变化 |
| --- | ---: | ---: | ---: |
| 帮助性 | 58.31% | 66.78% | +8.47 个百分点 |
| 安全性 | 39.15% | 42.54% | +3.39 个百分点 |

这些指标衡量模型对**数据已有回答**的倾向，不是新生成回答的安全准确率，也不是论文的成对胜率。发布策略的回答更长、重复较少，但仍可能配合不安全请求。完整结论见 [推理结果报告](RESULTS_LLAVA_ZH.md)。

## 作者用的 RM / CM 找到了吗？

**没有找到作者最终用于训练的 RM-V / CM-V checkpoint。** 我们知道它们的初始化模型、作用及训练实现，但这不等于已经拿到了作者训练后的模型。

论文 Appendix A.1 说明，两者从 **LLaVA-1.5-7B** 初始化：RM-V 学习帮助性偏好，CM-V 学习安全成本。它们是单独训练的评分模型，不是作者发布的最终策略。

本轮重新检查了公开来源：

- 作者 [Hugging Face 账号](https://huggingface.co/saferlhf-v) 当前只列出 `SafeRLHF-V` 模型仓库。
- [该模型仓库](https://huggingface.co/saferlhf-v/SafeRLHF-V/tree/main) 只包含 LLaVA、LLaVA-NeXT、Qwen 三个最终策略的权重，没有独立 RM/CM checkpoint。
- 上游 [issue #7](https://github.com/saferlhf-v/saferlhf-v/issues/7) 正在询问相同问题，目前仍为 open、没有回复。

这意味着**当前没有可直接使用的作者原始 RM/CM**，而不是证明作者从未在其他位置发布过。若继续训练复现，需要向作者索取，或依据公开实现自行训练；自行训练的权重不能冒称作者原始权重。
