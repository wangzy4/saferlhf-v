# 训练阶段进展与结论

**已完成两轮真实 RM/CM LoRA 和 256/64 全参数 v2 的训练与保存/恢复工程验收。第二轮 LoRA 有正面信号；全参数 RM 有学习信号，但 CM 质量未达标，完整 Safe RLHF-V 尚未复现。** 训练跑通与模型质量达标须分别判断。

## 本阶段的结论

- 公开实现中，RM 的帮助性标签、CM 的安全成本方向与 RL 成本惩罚意图一致，不应简单翻转 CM 的偏好顺序。
- 已处理确认存在的实现问题，为后续小规模训练验证做准备；这没有改变作者发布策略的权重，也不意味着模型能力已经提升。
- 第一轮 128/32 的 CM 未达标；第二轮 20 类、1,024/256 的 RM/CM 验证排序准确率达 78.52%/80.08%，CM 零阈值安全标签准确率 80.47%、AUC 0.883，高于多数类基线，值得继续。仍是内部评分验证，不代表 RL 后策略安全性。
- 所选 train 数据与内部验证、已用 evaluation 的精确图像重复已排除；尚未认证全量近似图像/语义泄漏，也未擅自改写少量排序与分级评分不一致的标签。
- **尚未找到作者实际使用的已训练 RM/CM checkpoint。** 若作者不提供，需要自行训练，且必须与“拿到作者原始权重”区分。

256/64 的全参数 v2 已完成：修正非持久 RoPE buffer 精度后，两模型整个内部 validation 重载最大分数差均为 0，optimizer 恢复与真实后续更新通过。RM 最终 85.94%，CM 56.25%，CM 零阈值全部判安全、balanced 50%，不能接 RL。下一步适度扩大样本并检查 CM 学习与校准，不凭单轮断言修正导致全部质量变化。LoRA/v2 产物均已 HF 私有归档并核对远端权重/metadata SHA256，CM 仅为未达标研究存档。当前不安排新增本地 judge。
