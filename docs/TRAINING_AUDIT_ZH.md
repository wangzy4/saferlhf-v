# 训练阶段进展与结论

**已完成两轮真实RM/CM LoRA和256/64、1,024/256全参数的训练与保存/恢复工程验收。最新1K全参数有正面内部评分信号，CM脱离全判安全状态；完整Safe RLHF-V仍未复现。** 训练跑通、评分质量与RL后策略质量须分别判断。

## 本阶段的结论

- 公开实现中，RM 的帮助性标签、CM 的安全成本方向与 RL 成本惩罚意图一致，不应简单翻转 CM 的偏好顺序。
- 已处理确认存在的实现问题，为后续小规模训练验证做准备；这没有改变作者发布策略的权重，也不意味着模型能力已经提升。
- 第一轮 128/32 的 CM 未达标；第二轮 20 类、1,024/256 的 RM/CM 验证排序准确率达 78.52%/80.08%，CM 零阈值安全标签准确率 80.47%、AUC 0.883，高于多数类基线，值得继续。仍是内部评分验证，不代表 RL 后策略安全性。
- 所选 train 数据与内部验证、已用 evaluation 的精确图像重复已排除；尚未认证全量近似图像/语义泄漏，也未擅自改写少量排序与分级评分不一致的标签。
- **尚未找到作者实际使用的已训练 RM/CM checkpoint。** 若作者不提供，需要自行训练，且必须与“拿到作者原始权重”区分。

256/64全参数v2的CM全判安全、balanced50%，保留未达标研究存档，不凭单轮断言精度修正导致全部质量变化。新的20类1,024/256全参数、3epochs/192updates已完整完成：RM/CM验证排序75.78%/80.08%，CM零阈值准确率85.94%、balanced85.87%、AUC0.932；194有害回答检出166/漏检28，318安全回答误报44。两模型全部256对重载差0、optimizer恢复/真实后续更新通过，每模型训练约19.7–19.8分钟、完整约27.5–27.6分钟，最高allocated/reserved61.86/66.14GiB。训练集99.12%/98.34%明显更高，后段验证loss升高，需继续检查泛化、分数校准及RL接入，不把数据增量视为已证明的唯一改善原因，不择中间最好epoch。

LoRA/256-v2产物已HF私有归档并核对远端权重/metadata SHA256，256-v2 CM仅为失败研究存档。最新1K全参数的训练/本地验收完成，HF归档仍在进行、两模型上传及哈希核验尚未确认全部完成。当前无RL、不安排新增本地judge。
