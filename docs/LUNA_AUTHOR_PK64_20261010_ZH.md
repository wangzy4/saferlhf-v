# Luna 判官：官方 64 题四策略 PK（2026-10-10）

## 范围与结论边界

本次比较的是**旧复现的四个冻结策略**：`base-before`、`base-after`、`safe-before`、`safe-after`。不是新算法 N32/b8/T4 的效果评测，也不是预算匹配的算法对照。

- `base-before` 为预训练 base，`safe-before` 为作者发布的安全策略。
- 两个 `after` 分别从对应初始化运行32次 actor RL/PTX 更新，使用自训1,024条规模 RM/CM，并非作者评分器或全规模论文训练。
- 新算法四轮工程结果及其本地诊断见 [N32独立报告](ACTIVE_SAFETY_V2_N32_ZH.md)；该新policy未参与下列Luna榜单。

复用 SafeRLHF-V `2503.17682v2` Appendix C 原 system/user prompt；按照用户授权，将论文 GPT-4o 判官替换为 iiot `gpt-5.6-luna`。因此是**原方法/prompt 的替换判官评测**，不是原判官的逐数值复现。实际响应的 model 字段通过匹配检查，但这不是服务端权重身份的独立核验。

冻结官方 64 题及原生图片，每题六个四策略配对，共 384 个计划请求。单个图文请求联合判断 helpfulness 和 safety；两维分别报告，不合成加权榜。图文失败不退化为纯文本。

## 主榜：强制偏好胜率

原 prompt/parser 使用二选一偏好，并不为相同回答或同分提供平局选项。下表保留该协议；**包含相同文本和同分样本**，胜率分母仅含有效判分。各策略预期分母均为 192，实际因失败而不同。

|Helpfulness 排名|策略|获胜/有效配对|胜率|平均原量表分数|
|---:|---|---:|---:|---:|
|1|safe-before|123/187|65.78%|1.9358|
|2|safe-after|109/190|57.37%|1.8947|
|3|base-before|75/191|39.27%|1.7330|

|Safety 排名|策略|获胜/有效配对|胜率|平均原量表分数|

这里 safety 的“排名”仅按**配对强制偏好胜率**排列，平均分排序并不相同。原 harmlessness 量表存在特殊拒绝评分规则，不能将其换算为不安全概率、人类风险或部署认证。

## 判官可靠性限制

两张左右颜色互换合成图通过，仅证明基础图像传输/辨识门禁，不证明正式样本的视觉推理或语义可靠性。文本 rationale 抽审发现：

- 部分 helpfulness 解释混入“不安全指导”等因素，可能存在维度泄漏。
- 虚构/艺术指导的 harmlessness 高分存在原量表校准疑问。
- 发生分数、偏好、额外排序矛盾，按严格标准拒收并保留。
- 当前助手的抽审未直接看图，不将 caption 或文本审阅冒充直接视觉核验。

故榜单保持有限、条件性解释，不作为人类风险认证。
