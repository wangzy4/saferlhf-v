# 项目主线：目标、实验计划与当前进度

> 更新于 **2026-10-20**。本页是当前主线总览，具体阶段变化见[10 月 20 日进展](PROGRESS_20261020_ZH.md)。旧复现总结已[单独归档](PROJECT_SUMMARY_20261013_ZH_ARCHIVE.md)，不作为当前运行状态。
>
> **一句话：先用作者公开偏好数据训练 Qwen3.5-4B 原生 RM／CM，再接回四卡 LoRA Joint-PPO＋PTX／双 critic 的 5K 实验；最终检验有限反馈预算下的安全性—帮助性收益。当前 CPU 数据准备完成，正式评分器训练和这轮策略训练均未开始，执行范围为“仅 CPU 收尾后停止”。**

## 1. 最终要验证什么？

项目从 SafeRLHF-V 复现出发，现在的研究重点是：**在外部反馈有限时，我们的 Joint-Gradient 方法能否比均匀查询／控制变量及 Marginal-Gradient 更有效地改善策略，同时兼顾安全性与帮助性？**

主方法利用密集的帮助性／安全代理信号，再用少量实际揭示的外部反馈进行校正，并围绕联合策略梯度分配查询。策略更新保留 PPO、PTX 和独立的 reward／cost critic。

这里的外部反馈是 **AI 评判反馈，不是人类标签或人类风险认证**。需要分别证明：

1. **评分器有效**：RM 能提供帮助性信号，CM 能提供危险成本信号，且能用于当前策略生成的回答。
2. **训练真实成立**：反馈校正、策略与 critic 更新、跨池状态以及保存恢复能正确衔接。
3. **方法确有收益**：在匹配预算和评测条件下，策略结果优于对照，而不只是代理分数上涨。

目前尚未完成第三项，**不能宣称 Joint-Gradient 已带来策略安全性、帮助性或反馈效率优势**。

## 2. 当前选定的主线

```text
作者已有公开偏好数据
        ↓
Qwen3.5-4B 原生 RM／CM：各用同一批5K偏好对训练
        ↓
验证偏好学习，以及对 Qwen 实际回答的代理信号
        ↓
重新确认评分映射、校正器和双 critic 初态
        ↓
四卡 Qwen LoRA Joint-PPO＋PTX：5K唯一prompt
        ↓
检查训练前后策略质量，再设计／执行预算匹配对照
```

### 两类训练不能混淆

| 项目 | 当前计划 |
| --- | --- |
| 基础视觉语言模型 | **Qwen/Qwen3.5-4B**，使用其原生图文模板 |
| RM：帮助性评分器 | 独立模型；更有帮助的回答得分更高 |
| CM：安全成本评分器 | 独立模型；更危险的回答成本更高 |
| 评分器结构 | Qwen 原生骨干＋末端隐藏状态上的无 bias 标量头；迁移作者评分头／训练目标思想，**不套用 LLaVA 骨干或 tokenizer** |
| 评分器训练方式 | 语言部分、视觉 merger／投影与评分头全参训练，视觉 tower 冻结；**不是 LoRA 评分器** |
| 后续策略训练 | **LoRA Joint-PPO＋PTX／双独立 critic**，不是把策略也改成全参数训练 |
| 方法精度边界 | 保留全部实际可训练 LoRA 坐标的严格联合梯度计算；不以 affine、sketch 或参数抽样替代 |

原 7B 的复现、严格几何验证及实验方案保留，八卡 7B 5K 路线延后，不与当前四卡 Qwen 主线混算或自动并行启动。

## 3. 为什么先修评分器，而不是直接跑策略？

旧 LLaVA 评分器在偏好排序上确实学到了信号，但**成对排序能力不等于对新策略单条回答的可靠绝对评分**。

Qwen 的 192 条新校准已完成，按预定的 64 条拟合／128 条验证检查后：

- RM 映射后的验证 Spearman 约 **−0.070**，均方误差未胜过常数基线。
- CM 映射后的验证 AUC 约 **0.624**，未通过原定筛查；验证集中只有 5 条 unsafe，估计也存在较大不确定性。
- 结束位置、回答风格和数据分布诊断解释了部分偏移，但没有修复 RM，也没有提供继续策略训练的充分依据。

因此决定：**暂停策略更新，改用公开偏好数据训练原生 Qwen 评分器，而不是继续用不可靠代理消耗策略纠正预算。**

这里实际校准的是旧小规模 LLaVA 代理，并非作者原始 checkpoint，也不是已完成的约30K作者规模评分器那一组。不能据此否定所有旧评分器，也不能反过来用旧排序指标替新分布放行。

## 5. 已定规模与反馈预算

### 原生评分器

- RM、CM **各用同一批5,000对已有公开偏好数据**，另有512对内部验证。
- 各固定训练 **3 epochs、939次更新**；完整保留每 epoch 的5,000对，包括尾8对，不按验证表现挑 epoch。
- 这些已有标签**不新增付费反馈，也不消耗策略阶段625条纠正额度**。

### 后续策略5K

- **5,000个唯一 prompt，160次计划策略更新**，配套 PTX 和双 critic。
- 每1,000题构成一段：31个32题池＋1个8题尾池；每个满池查询4条，尾池查询1条，合计每段125条、五段 **625条训练反馈**。
- 每1,000题保存完整可变状态，验证新 checkpoint 后再原子提交并清理旧版本，正常只留最新完整版本。
- Qwen 既有校准 **192条已消耗**；策略训练625条尚未使用；当前合计上限817，**额外终点评分预算为0**。不自动扩额，也不与独立7B预算混用。

当前5K是主线训练计划，**不是三个方法各已获一份625条预算**。后续完整方法对照、独立终点评测及其反馈开销，需要另行冻结方案与授权。

## 6. 下一步的任务顺序

1. **当前先停止。** 已明确限定为仅 CPU 收尾，不留后台训练／等卡队列；新 GPU 工作须重新授权。
2. 获准且资源可用后，完成评分器实际四卡容量、完整保存、真实尾批和新进程下一步恢复验收。
3. 验收和训练授权具备后，训练 RM／CM，验证内部偏好任务，并检查对 Qwen 回答的信号。已有192条只能作为开发／诊断对照，不冒充新的独立盲测。
4. 根据新评分器重新确认映射、ONS 校正器和 critic 初态；不默认继承旧 LLaVA 状态。
5. 接通真实反馈校正与 PPO＋PTX／双 critic，先验收真实一池、下一 fresh 池及跨池恢复，再推进5K。
6. 在有效代理和完整训练结果的基础上，开展预算匹配对照，报告安全性、帮助性、反馈量和实际成本；零收益或负收益同样保留。

**现在的关键里程碑是“可信的新评分器”，不是“先让策略跑起来”。CPU 准备已交付，正式训练与方法收益仍待验证。**
